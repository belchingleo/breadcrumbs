# Breadcrumbs · 思路

Breadcrumbs 用于核对和复盘较长的 Claude Code、Codex 对话。

它不重新总结 AI 说过什么，而是回答两个问题：

1. 这段对话有哪些问题被忽视、悬置、待处理？
2. 用户的注意力是否发生过漂移，思路链是什么样的？

## 两个命令

| 命令 | 用途 | 结果 |
|---|---|---|
| `/crumbs` | 核对当前窗口的漏答、漏做、待确认和未兑现承诺 | 逐项裁决，随后给出总结与下一步 |
| `/bread` | 完整复盘一段长对话 | 生成本地交互式 HTML |

在 Codex 中使用 `$crumbs`、`$bread`，也可以直接用自然语言触发。

## `/crumbs`：面包屑拾遗

长程对话跨度长、密度高，用户的记忆力、注意力伴随着对话的拉长都有一定程度的下降
容易有意或无意留下以下几类问题：

- 用户一次提出多项要求，AI 只完成了一部分；
- AI 反问澄清问题，原问题随后没有被回应；
- AI 显示处理，但没有交付；
- AI 等待确认、选择、材料或外部动作；
- 双方在一个未经确认的前提上继续工作；
- 用户暂时搁置了一件事，后来没有再回到它。

`/crumbs` 先用结构规则定位候选，再让独立小模型核对有限证据。它不会把规则命中
直接宣布成“遗漏”。

以提问的方式，帮助用户在结束长程对话时随手拾遗。每次只展示一个问题，用户需要选择：

- **处理**：加入本轮行动；
- **已处理**：确认此前已经闭环；
- **忽略**：主动关闭，后续不再提醒。

未回答的问题保持为待决定状态，不会因为展示过而消失。全部问题得到裁决后，
`/crumbs` 会生成一份简短的对账结果，并给出下一步行动。

```text
结构定位
  → 独立核验
  → 逐项裁决
  → 对账总结
  → 下一步行动
```

同一窗口重复调用时，已经裁决的事项不会重复出现。

## `/bread`：复盘面包

`/bread` 沿着用户输入的prompt重建讨论路径，复盘长程对话中用户与AI关于话题：

- 从哪里开始；
- 注意力在哪里分叉；
- 每条思路留下了什么；
- 哪些问题仍未收束；
- 哪条分叉思路值得再次探讨。

结果是一份本地 HTML，包含来路图、复盘总览、思路复盘和原话证据。

[查看完全虚构的交互演示](https://belchingleo.github.io/breadcrumbs/)。
演示不包含真实用户数据。

## 安装

运行前提：Python 3 标准库。无需虚拟环境或额外 Python 依赖。

```bash
git clone https://github.com/belchingleo/breadcrumbs.git
cd breadcrumbs
python3 scripts/install.py --target both
```

也可以只安装到一个宿主：

```bash
python3 scripts/install.py --target claude
python3 scripts/install.py --target codex
```

再次运行安装命令即可更新。旧版本会保留在 skill 目录之外的备份目录中。

## 可信度

- 用户提示词是任务契约，AI 回复是履约证据；
- 结构规则只负责定位，语义结论由独立 evaluator 核验；
- `open` 必须说明检查范围和缺少的证据；
- 用户沉默不能被解释成放弃；
- 证据不足时使用疑问语气，低可信候选不展示；
- 分析与标注身份不匹配时，拒绝生成报告。

Claude Code 默认使用 Haiku 核验，失败时回退 Sonnet；Codex 默认使用
`gpt-5.6-luna`，失败时回退 `gpt-5.6-terra`。两者只接收裁剪后的证据包。

## 隐私

会话读取、结构分析、证据裁剪和 HTML 生成都在本地完成。

`/crumbs` 的账本只保存候选哈希与状态，不保存原话。`/bread` 生成的 HTML 会内嵌
用户输入；分享前应自行检查。公开演示必须使用虚构或充分脱敏的材料。

## 边界

- 当前一次只处理一个会话；
- `/crumbs` 对显式言语行为最可靠，不保证识别隐含假设或长距离语义改口；
- `/bread` 的路径算法提供候选结构，最终语义名称仍需模型核实；
- 同一主题跨窗口的连接尚未实现。

## 测试

